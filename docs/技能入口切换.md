# 商机技能入口切换与回退

旧入口是聊天技能自己选方法，再调用话题信号雷达的各条来源。新入口只调用 AIPO 的三个 MCP 工具，由服务规划、取证、归档和写报告。

## 现在用哪一份

| 角色 | 路径 | 行为 |
| --- | --- | --- |
| 新快捷入口 | `skills/where-are-moneys/SKILL.md` | 只调用 `start_research`、`get_research`、`resume_research` |
| 原入口 | `legacy/skills/where-are-moneys/SKILL.md` | 保持迁入时的正文，仍按路线表调用雷达和其他方法 |

本轮没有修改 `legacy/skills/where-are-moneys/` 里的文件。回退不需要从 Git 历史里找回正文。

## 切换到服务

1. 按 `docs/服务启动.md` 启动 `python3 -m aipo serve`，并在宿主里配好 MCP。
2. 把宿主技能目录指到本仓库的 `skills/where-are-moneys`，或让技能加载器读取这份新的 `SKILL.md`。
3. 用一句话试一次。调用方不应该再出现对小红书 MCP、`goofish` 或其他上游的直接工具调用。

如果宿主以前把 `~/.agents/skills/where-are-moneys` 指到旧目录，把这个符号链接改到新目录即可。

## 回退到原入口

1. 把宿主技能目录或符号链接改回 `legacy/skills/where-are-moneys`。
2. 原技能会重新按 `references/routes.md` 和话题信号雷达工作。雷达脚本仍在 `legacy/topic-signal-radar/`。
3. AIPO 服务可以继续单独开着，也可以停掉。停服务不会改旧技能的文件。

回退后，平台登录、采样和归档仍以雷达的平台共同规则和 `scripts/save_run.py` 为准。不要把服务里的回放报告当成原入口的新实采。
