# 平台、依赖与实测状态

首版范围覆盖原 AIPO 雷达在用的八个项目及宿主公开网页。每个项目的来源定位、提交或版本、许可和本机参考文件指纹见 [依赖清单](依赖清单.json)。平台按任务择用，在同一版交付中实现其适用的直读、公开补读或导入能力。上游动态增设的渠道由来源的实际配置决定。

## 项目取舍

- **直接调用的来源。** 小红书、闲鱼、国内外近 30 天检索、原文补读。保留上游已有搜索和读取实现。每个平台只维护实际使用的接口映射，避免两份上游给同一条数据增加虚假佐证。
- **补充取证与导入。** MediaCrawler、社媒助手、闲鱼监控。依任务配置现成能力，闲鱼监控继续通过已有导出接入。MediaCrawler 本地许可证标明仅限非商业学习用途，商业场景应接许可符合的等效来源或已授权导出。[上游许可](https://github.com/NanmiCoder/MediaCrawler/blob/main/LICENSE)
- **闲鱼上线边界。** 已实测可用和生产接入条件分别记录。闲鱼社区法律声明对第三方智能体或自动化访问要求事先明确书面许可和必要评估。交付保留闲鱼接入、样本回放与导入，并在有相应授权的环境复验站内路径。[闲鱼社区法律声明](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_taobao/suit_bu1_taobao202103061039_91765.html)
