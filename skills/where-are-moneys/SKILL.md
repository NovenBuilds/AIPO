# 赚钱机会快捷入口

这个入口把研究交给 AIPO 服务。聊天侧不再逐个调用小红书、闲鱼、检索脚本或导入工具。

## 调用

1. 确认宿主已经连接 MCP 服务 `aipo`。启动方式见仓库 `docs/服务启动.md`。
2. 调用 `start_research`，`question` 使用用户原话。用户明确点了平台时，把平台放进 `platforms`。需要防重复时带上同一个 `request_id`。
3. 用 `get_research` 看状态。等到「已完成」「等待用户」或「失败」。
4. 「等待用户」时，把来源里的中文阻塞原因告诉用户。用户补充登录、配置或选择跳过后，调用 `resume_research`，把原话放进 `answer`。
5. 把服务返回的中文报告交给用户。报告里的 `[E…]` 编号对应归档证据，不要另编出处。

服务不可用时停下来说明原因。不要改回多个平台工具拼一份报告。

## 怎么读结果

- 报告首行的登记是「回放」「导入」「受阻」或「实采」。回放、导入和受阻都不是实采。
- 路径里的 `in-site` 是站内，`public-index` 和 `public-clue` 是公开索引或公开线索。公开线索不能代替站内样本。
- 挂牌价不是成交价。证据不足时报告会保留结论缺口，并减少建议方向。
- 旧雷达的证据编号和批次仍在任务归档目录里。已完成批次在恢复后继续可引用。
