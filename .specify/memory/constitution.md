# AIPO 章程

## Core Principles

### 一个入口
对外只保留一个研究服务。调用方用一句话发起研究，不自己调用各个平台工具。

### 复用已登记来源
首版覆盖已经登记的平台和来源。同一平台只维护一条可复验的主路径。补充来源必须在证据里标明实际渠道。

### 回放不是实采
回放、导入和真实平台请求分开登记。没有真实返回时，不得用样例填成实采。

### 程序守边界，模型做判断
模型可以规划关键词和来源、选择深读样本、根据证据写判断。程序控制任务、预算、超时、存储和引用校验。模型不能新增未登记来源，不能把挂牌价写成成交价，也不能把未实采写成实采。

### 证据可回读
每条证据保留稳定编号、平台、路径、读取深度和原件引用。中断后按原任务编号恢复，已完成批次继续可引用。

## 交付约束

平台登录和模型密钥只从运行环境进入，不写入仓库。上游源码按依赖清单独立获取，不提交进本仓库。MediaCrawler 只导入已有文件，不在本服务里启动爬虫。

## 验收

接口、离线回放和真实平台请求分别记录。真实请求写明版本、读取深度和证据。登录、授权或配置缺失时记下已尝试的方法和最少还缺的输入，并继续做不依赖该输入的部分。

## Governance

产品规则以 `docs/架构与契约.md`、`docs/Grok交接.md` 和 `docs/平台与依赖.md` 为准。本章程只重述这些已有约束，不另立范围。
