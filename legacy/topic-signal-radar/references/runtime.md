# 按需运行准备

仅在安装、来源不可用、连接失败或缺少能力时读取。已有宿主工具或专用服务正常时，依照所选来源说明查询，不先运行全量环境检查。平台行为遵循[共同规则](platform-access.md)。

## 针对来源诊断

根目录以解析后的雷达路径定位。先看 `configs/local.json`，没有则使用 `upstream/<项目名>`；覆盖格式见[示例配置](../configs/example.json)。配置只存路径、解释器和无凭据地址。

```bash
python3 "$RADAR_ROOT/scripts/check_env.py" --project xiaohongshu-mcp --json
# 仅确需检查该服务接口时追加 --probe
```

脚本只检查选定来源的本地条件；显式省略项目参数才检查全部上游。它不发现宿主工具或插件，不因源码、模块、会话文件存在就认定真实请求成功。`--probe`触及服务接口，可能触发服务端浏览器；认证报错应先核对已有安全配置，不将其当未登录。工具不在全局路径不代表专用环境缺失。

## 准备与维护

优先复用上游专用环境，不安装进系统Python或混用八个项目的环境。海外版最低Python3.12，Agent-Reach为3.10，MediaCrawler和goofish-cli为3.11；当前项目清单优先。安装只准备本次所需依赖，不自动升级、重置源码或启动其他后台；失败保留原因，不循环重装。

中文版浏览器按其技能第6节核对Python Playwright、浏览器启动与实际来源读取；JavaScript包不能代替Python依赖。共享服务正常时不重复准备浏览器。

上游修改说明见[补丁记录](../patches/README.md)。更新前核对本地差异与基线，不自动拉取或重置。共享技能入口是指向雷达目录的软链接；既有异目标文件不得覆盖，客户端识别以实际宿主为准。
