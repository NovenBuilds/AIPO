# 平台取证共同规则

本页统一维护平台研究的接入、授权、采样及停止条件。来源参数只读所选调用说明：小红书用[本机调用卡](providers/xiaohongshu-mcp.md)，其余从[雷达入口](../SKILL.md)按任务选路。

## 接入与恢复

1. 优先检查已知、获选的宿主工具或专用服务，查看当前输入契约并实测会话；在已授权范围内取样。不因文件存在认定已登录，也不为正常查询重新扫描全部入口。
2. 复用同来源、账号和范围的已有授权；首次使用或中转、权限、账号、范围改变时，说明来源、账号或身份未知、数据流、数量、本地归档及验证／账号限制风险，让用户选择继续、手动提供数据、公开资料初筛或暂停。未选择不采集，不将沉默当同意。
3. 缺登录则提供对应来源的可见官方页或二维码，由用户本人操作；恢复后重验。首次真实搜索、一篇详情及评论检查直接计入样本，分别记录可用、空、受限或失败，不另跑重复验收请求。
4. 连接失败或能力不足，再发现本次平台的其他宿主工具、配置服务、插件及已有专用浏览器；记录各入口状态。一个端口失败不代表平台不可用。安装、注册或连接变更先给具体方案与权限，不自动轮换来源或复制日常浏览器会话。
5. 验证码由用户处理；限流、封禁或审批阻断则停止受影响路径，说明具体协作步骤，不反复重试、换号或绕过。缺关键数据不自动改用公开网页交付完整推荐。

凭据由原工具本机管理；不索取、展示或写入研究原件、聊天及日志。只读公开材料，不发帖、点赞、回复、私信、交易或启动监控；私人交易后台另行授权。

## 采样与证据

- 平台商机默认设计 **3组关键词**，覆盖求助与需求、供给与替代、反馈与反面意见；最多 **30篇去重笔记、6篇深读，每篇最多20条评论**，默认近30天。普通查询与用户指定范围按实际任务执行。
- 加载前核对工具能否限制数量；下一请求可能越界时先说明并协商范围。意外整页超额如实记录并停止扩采，不以事后截断冒充严格未超，不无限翻页或凑数。首轮验收计入总量，内嵌回复也计评论数。
- 用真实笔记标识计样本，保留完整链接和原件；证据索引沿用[归档契约](evidence.md)。记录关键词、去重数、读取深度、截断、失败、获取时间和实际发布日期范围；日期未知就标未知，不能用检索日期代替，也不擅自扩窗。
- 核对相关性、作者独立性、推广偏差、时效与交叉印证；兼顾求助、供给和反对意见。样本多不等于可信；自评、接单宣传、自动总结和重复回复不直接算独立买方证据。关键内容在配图时补读，摘要不等于正文。
- 分开记录热度、报价、收入自述、公开销量、可核验成交和净利润；普通笔记及评论不保证真实订单。

## 交付状态

| 状态 | 允许交付的范围 |
| --- | --- |
| 接入未完成 | 已检查入口、阻断原因和下一步协作动作 |
| 公开资料初筛 | 用户选择后的公开事实与假设，注明缺少站内证据 |
| 取得站内样本 | 实际数量、正文／评论覆盖及据此支持的判断；只有卡片时限于摘要线索 |

材料不足给阶段性发现，不维持预设三个方向。重跑新建任务并链接旧报告，说明判断如何改变，保留旧原件与报告。
