# 商机与产品技能索引

整理日期：2026-11-03（北京时间）。新增 72 项技能：PM Skills（产品管理技能套件）69 项，加市场研究、产品诊断、产品视觉构思 3 项。另链接已有的话题信号雷达，保留 73 个底层技能条目；另新增总入口，合计 74 个入口。

本目录帮助你围绕“做什么项目、应用或平台业务更有盈利可能”选择研究方法。技能负责组织研究和验证；具体结论应有来源，并区分事实、推断、假设与实际付费结果。

## 优先使用总入口

[Where-are-moneys（赚钱机会总入口）](~/.agents/skills/where-are-moneys/SKILL.md)

直接输入 `$where-are-moneys`，入口会先问你要找新项目、评估已有想法，还是研究某个平台。已有具体目标时可以直接接在后面，例如：`$where-are-moneys 我想评估面向小商家的文档整理工具`。

它会复用当前聊天中的条件，只对关键缺项一次问一个问题，按需选择下面的技能，先交付简短判断，选中方向后继续深入。原有分类与调用示例继续保留，便于需要时单独使用。

## 推荐使用顺序

发现需求 → 市场研究 → 产品诊断 → 变现方案 → 付费验证 → 产品设计。

| 步骤 | 优先技能 | 期待得到的结果 |
| --- | --- | --- |
| 发现需求 | [话题信号雷达](~/.agents/skills/topic-signal-radar/SKILL.md) | 重复出现的问题、原始来源、反面证据与覆盖缺口 |
| 市场研究 | [市场研究](~/.agents/skills/market-research/SKILL.md) | 竞品、价格、替代方式、渠道与进入机会 |
| 产品诊断 | [产品诊断](~/.agents/skills/product-lens/SKILL.md) | 具体客户、痛点、是否值得做与最小验证版本 |
| 变现方案 | [变现策略](~/.agents/skills/monetization-strategy/SKILL.md)、[定价策略](~/.agents/skills/pricing-strategy/SKILL.md) | 谁付费、买什么结果、如何收费与成本假设 |
| 付费验证 | [新产品低成本实验](~/.agents/skills/brainstorm-experiments-new/SKILL.md) | 实验方法、行为指标、成功门槛与停止条件 |
| 产品设计 | [产品视觉构思](~/.agents/skills/ideate/SKILL.md)、[产品需求文档](~/.agents/skills/create-prd/SKILL.md) | 确定需求后的设计方向与可交付需求 |

研究“哪个平台做什么能盈利”时，配合入市策略、首批客户选择和获客方式选择，比较平台 × 人群 × 痛点 × 产品或服务 × 收费 × 获客成本 × 交付成本 × 验证办法。平台准入、收费规则和公开数据需按当次研究核查。
