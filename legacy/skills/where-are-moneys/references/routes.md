# 按问题选方法

先选一项主方法，执行其工作流；其他技能只补本次缺口，不重复分析同一材料。将当前目标、条件和证据交给所选技能，模板中的占位参数由实际任务替换。

| 任务 | 主方法 | 何时补充 |
| --- | --- | --- |
| 找新项目 | [市场研究](../../market-research/SKILL.md) | 先取证，再收敛客户和方向 |
| 评估想法 | [产品诊断](../../product-lens/SKILL.md) | 已有材料先用，补查影响决定的事实 |
| 平台机会 | [市场研究](../../market-research/SKILL.md) | 先经[平台入口](platform-research.md)取得站内材料 |

## 按缺口增加

| 缺口 | 方法与边界 |
| --- | --- |
| 近期讨论、正文、评论或商品材料 | [话题信号雷达](../../topic-signal-radar/SKILL.md)：只选必要来源 |
| 人群太宽／先服务谁 | [市场细分](../../market-segments/SKILL.md)比较群体；[首批客户](../../beachhead-segment/SKILL.md)选择切入口 |
| 需要逐个竞品深比 | [竞品分析](../../competitor-analysis/SKILL.md)；市场研究已有初筛时不重复 |
| 谁付费／具体价格 | [变现策略](../../monetization-strategy/SKILL.md)选收费模式；[定价](../../pricing-strategy/SKILL.md)再定价格和单位 |
| 哪些判断未证实／先验什么 | [识别假设](../../identify-assumptions-new/SKILL.md)、[假设排序](../../prioritize-assumptions/SKILL.md)；不重复产品诊断已有答案 |
| 具体试点与付费实验 | 新项目用[新产品实验](../../brainstorm-experiments-new/SKILL.md)，改进现有产品用[已有产品实验](../../brainstorm-experiments-existing/SKILL.md) |
| 通过什么方式获客／怎样上线 | [获客方式](../../gtm-motions/SKILL.md)选渠道；[入市策略](../../gtm-strategy/SKILL.md)制定落地计划 |
| 用户明确要求设计／需求文档 | [视觉构思](../../ideate/SKILL.md)、[产品需求](../../create-prd/SKILL.md)；不由研究自动触发 |

这些是16项可选技能的入口，保留各自职责和必要产物。需要其他方法再查[中文索引](../../商机与产品技能索引.md)。
